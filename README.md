# hxwl-11 角膜塑形镜试戴与复查准入台账

在验光看板基础上改造的角膜塑形镜(OK镜)试戴与复查准入台账。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口:5111

## 功能

- **患者登记**:每名患者登记双眼基弧、角膜曲率(平K)与散光,自动判定是否超出适配范围
- **试戴片库存**:试戴片按左右眼型号管理,占用状态实时展示
- **试戴安排**:同一试戴片重叠时段不得重复分配(R4),预约即拦截
- **试戴确认门槛**:参数超出适配范围(R1–R3)或名下有试戴片未归还(R5)时不能确认试戴
- **复查登记**:复查必须承接上次镜片批次(R6);镜片或角膜异常须写明原因并保留原批次(R7)
- **冲突台账**:被拦截的预约/确认/复查列出患者、镜片编号、参数和命中的限制
- **修订记录**:登记、预约、确认、归还、复查、拦截全程留痕
- **持久化**:localStorage 保存台账,刷新后患者、试戴占用、复查和修订记录自动做对应校验

## 准入限制

| 规则 | 内容 |
| --- | --- |
| R1 | 基弧须在 7.40–8.60mm |
| R2 | 角膜曲率(平K)须在 40.00–46.00D |
| R3 | 散光须 ≤1.50D |
| R4 | 同一试戴片重叠时段不得重复分配 |
| R5 | 试戴片未归还不得确认新的试戴 |
| R6 | 复查须承接上次镜片批次 |
| R7 | 镜片/角膜异常须写明原因并保留原批次 |

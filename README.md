# hxwl-11 角膜塑形镜试戴与复查准入台账

由验光看板改造的角膜塑形镜（OK 镜）试戴与复查准入台账。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5111

## 功能

- **患者登记**：每名患者登记基弧（mm）、角膜曲率（D）、散光（D，负柱镜记法），实时给出适配评估
- **适配范围**：基弧 7.50–8.60mm、角膜曲率 40.00–46.00D、散光 ≤1.50D
- **试戴占用**：试戴片按左右眼型号（OD/OS）占用，同一镜片重叠时段不能重复分配
- **确认试戴准入**：参数超出适配范围或试戴片未归还时不能确认试戴；确认后患者承接该镜片批次
- **复查准入**：复查必须承接上次镜片批次；镜片或角膜异常必须写明原因并保留原批次，正常时可沿原批次或换发新批次
- **修订留痕**：患者参数修订必须填写原因，逐字段记录原值/新值
- **冲突拦截**：被拦截的操作列出患者、镜片编号、参数和命中的限制
- **持久化**：患者、试戴占用、复查、修订与冲突记录存入 localStorage，刷新后数据对应不丢失；可一键恢复示例数据
